# Confirmation questions (ask with AskUserQuestion before building the plan)

Write questions in Bahasa Indonesia. Make every option specific to the clip: name the moment
("saat bilang 'doomscrolling' ~0:12"), the idea, and what would appear on screen.
Max 4 questions per AskUserQuestion call; split into two rounds if needed.

## Round 1: layout & B-roll decision

**Q1. Format & layout** (single select)
- 9:16 contain-blur (Recommended when the footage has burned-in captions): 16:9 frame kept whole in the middle,
  blurred fill above/below, original captions stay intact.
- 9:16 full crop: fills the screen, punch-ins hit harder, but text at the frame edges gets cut off.
- 16:9 original: for YouTube/landscape.

**Q2. B-roll: pakai atau tidak?** (single select)
- Tidak pakai B-roll. Pure A-roll + word pop-ups (fastest, raw podcast feel).
- Pakai, sedikit (1–2 sisipan di momen kunci).
- Pakai, padat (setiap 6–10 detik, gaya reel referensi).

**Q3. Jenis B-roll** (multi select, only if Q2 = pakai)
Tailor to the topic. Typical options:
- Stock footage/visual ilustrasi sesuai kalimat (e.g. orang scroll HP di kasur, notifikasi bertubi-tubi).
- Footage milik 7summits (produk/alat rental, BTS produksi, toko Cisaranten/Sriwijaya). User provides the files.
- Screenshot/screen recording (artikel, berita, postingan) sebagai bukti/konteks.
- Teks kutipan/ayat/data full-screen (quote card), styled with the keyword fonts.

**Q4. Momen B-roll** (multi select, only if Q2 = pakai)
List 3–4 concrete moments from the transcript with what would be shown, e.g.:
- "0:08 'Doomscrolling' → close-up jempol scroll HP, B&W, zoomblur"
- "0:21 'orang sibuk kena' → split-screen: kantor sibuk / scroll HP"

## Round 2: details (only when B-roll is used)

**Q5. Layout B-roll** (single select)
- Full-screen (imersif, dramatis).
- Split-screen 2 panel (bandingkan dua hal: sebelum/sesudah, hasil/BTS).
- Campuran, ditentukan per momen.

**Q6. Look B-roll** (single select)
- Warna natural.
- Hitam-putih untuk close-up alat/produk, warna untuk adegan.
- Hitam-putih semua (mood serius/reflektif).

**Q7. Sumber file** (single select)
- Saya upload sendiri (ask for the files/Drive link and the credit @handle if third-party).
- Carikan stock bebas royalti (Pexels/Pixabay); list links for approval before downloading.
- Pakai potongan dari video itu sendiri (cutaway/insert dari bagian lain).

**Q8. Word pop-up** (multi select)
Offer the 4–6 strongest words/phrases from the clip with suggested highlight:
`"DOOMSCROLLING" (box oranye)`, `"BERHENTI SEJENAK" (hijau)`, ... plus "Pilih sendiri".

Never insert B-roll, stock, or third-party clips the user did not confirm.
