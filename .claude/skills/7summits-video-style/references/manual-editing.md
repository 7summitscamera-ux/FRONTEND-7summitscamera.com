# Manual recipe (CapCut / Premiere / DaVinci)

For editors who cut by hand. Values match `assets/style.json`.

## Project
- 1080×1920, 30 fps (or 60 if the source is 60). Export H.264, high bitrate, audio −14 LUFS.

## Cutting
1. Remove every pause > 0.3 s and filler ("eee", "jadi gini", repeats).
2. On every cut, alternate scale 100% ↔ 115% (CapCut: Basic → Scale; Premiere: Effect Controls → Scale).
   Keep the eyes at the same height (~38% from top).
3. Shots 2–4 s. Hook (first 3 s) = the question or the strongest claim.

## Captions
- CapCut Auto Captions → font Inter SemiBold (or Helvetica Neue Medium), size so a 6-word line ≈ 80% width,
  white, stroke black 1–2, shadow on. Position: chest, ~51% from top. Animation: "Typewriter" or word-by-word.
- First 3 s: add a "|" cursor at the end of the line.
- **If the footage already has captions, skip this step.** Add word pop-ups only, and never at the same time
  or same spot as existing pop-ups.

## Word pop-up (keyword card)
- Text UPPERCASE, Inter ExtraBold (or Helvetica Neue Bold), tracking −1, size ~2.2× caption.
- Main point: white text + orange box #FA6C00 (CapCut: Background, opacity 100%, rounded 0).
- Contrast/comparison: text green #45FA00.
- Optional small lead line above (caption font), optional italic serif connector ("ke", "vs") between two lines.
- In animation: "Pop"/"Zoom in" 0.14 s (118% → 100%). Hide the normal caption while the card is shown.
- Max 1 card per 5–8 s.

## B-roll (only when confirmed)
- Full-screen or split-screen: two 16:9 panels stacked in the middle over a blurred copy.
- Gear/product: B&W + contrast, slow zoom 100→108%.
- Credit @handle bottom-right for third-party clips.

## Transitions
- A-roll ↔ B-roll: "Slide up"/"Push up" 0.3 s + motion blur + whoosh SFX.
- Into gear close-up: "Zoom in" + blur 0.3 s.
- B-roll → B-roll: "Zoom out/through" + dip to black.
- A-roll ↔ A-roll: hard cut only.

## Branding
- Watermark top-center: logo circle + "7summits" (bold) "camera" (regular), white, small. Only on A-roll.
